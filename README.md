# shspokerogue

A GitHub Pages deployment of the open-source PokéRogue project.

The deployment workflow builds the `beta` branch of the upstream `pagefaultgames/pokerogue` repository and publishes the generated site to GitHub Pages.

## Deployment

Enable **Settings → Pages → Source: GitHub Actions** in this repository. The workflow then deploys on pushes to `main`, manual runs, and a daily scheduled build.
